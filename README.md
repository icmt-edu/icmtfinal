# ICMT Professional Education Website

Static multi-page website for the Intercontinental Center of Medical Training.

## Included
- Homepage with quick-access buttons for Study, CME, Webinars, Enrollment, Payment, Certificate Verification, Faculty and Events
- 45 specialty/professional departments
- 135 individual course pages
- Enrollment page
- Payment placeholder page
- Certificate verification placeholder page
- Faculty page
- Events and webinars
- Cooperating Institutes & Credentials page
- Contact page
- Floating chatbot-style quick-help widget
- Responsive mobile design

## Important
This is a static website. It does not yet:
- accept live payments
- store enrollment applications
- send contact-form emails
- verify certificates against a database
- provide a true AI chatbot

Those features require secure backend services or third-party integrations.

## GitHub
Upload every file and folder to the repository root.

## Hosting
Works as a static site on GitHub Pages, Vercel, Netlify or Cloudflare Pages.
No build command is required.

## Important deployment note
This rebuilt version is self-contained:
- CSS is embedded directly in every HTML page
- JavaScript is embedded directly in every HTML page
- The ICMT logo mark is rendered with HTML/CSS
- There is no assets folder dependency

This prevents the unstyled-page problem that occurs when nested asset folders are not uploaded correctly.
